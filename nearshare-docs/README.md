# NearShare — Vibecoding Doc Bundle

Offline, encrypted, wireless file-sharing app (host → many clients), targeting 50GB in <30min, with pause/resume and a lightweight ML-driven transfer optimizer.

## Docs in this bundle
1. `01-PRD.md` — what you're building and why
2. `02-tech-stack.md` — recommended stack + reasoning
3. `03-architecture.md` — components and data flow
4. `04-features.md` — MVP vs later features checklist
5. `05-ml-plan.md` — the ML feature, scoped honestly
6. `06-folder-structure.md` — suggested project layout
7. `07-roadmap.md` — phased build plan

## How to use these with an AI coding assistant
Feed `01-PRD.md` + `03-architecture.md` first for context, then work phase-by-phase from `07-roadmap.md`. Paste the relevant doc section when asking for a specific module (e.g. paste the chunker section of `03-architecture.md` when asking to build `chunker.dart`).
